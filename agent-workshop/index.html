From Chatbot to Coworker: Your First AI Agent

You've used AI that answers. Now try AI that does the work: it reads your files, builds tools, sorts an inbox, and fixes its own mistakes, right on your own computer. No programming required.

Starter folder for the fictional Crawdad Junction Catering: instructions for the AI, business rules, 40 customer emails, sales data, and a buggy tool to fix.

Download the starter folder

What's different about an agent?

Chatbot (generative AI)You ask; it writes an answer. You copy, paste, and do the work.
Agent (agentic AI)You give it a goal; it makes a plan, opens files, creates real files, runs them, checks its work, and fixes mistakes.

1Unzip the folder

Find the downloaded zip, right-click → Extract All → Extract. Mac: double-click the zip. Work from the extracted folder.

Don't skip this. If you open the folder inside the zip, the AI can't save anything.

2Install one agent app

Codex (OpenAI)

Works with a free ChatGPT account

  1. Install the ChatGPT desktop app. Windows: Microsoft Store, search "ChatGPT." Mac: chatgpt.com/download.
  2. Sign in.
  3. Open Codex in the app and choose the extracted folder.

Claude Code (Anthropic)

Needs a paid Claude plan (Pro or higher)

  1. Install the Claude desktop app from claude.com/download.
  2. Sign in.
  3. Open the Code tab and choose the extracted folder.

No terminal, no programming tools, no admin rights. Windows or Mac laptop required; Chromebooks and phones won't run the desktop apps.

3Say hello

Paste this as your first message:

First promptWhat's in this folder, and what instructions were you given?

If it describes Crawdad Junction Catering, you're set up. If it says the folder is empty, you opened the wrong folder; go back to Step 1.

4Put it to work

Try these in order. Each one is bigger than the last.

Build a toolBuild a catering quote calculator from business_rules.md that I can open in my browser.
Do a choreGo through every email in the inbox. Sort them into folders by type, draft a reply to each one that follows our rules, flag anything a manager must see, and make a summary spreadsheet.
Analyze dataTurn data/sales.csv into a one-page dashboard. What are the three most important things the owner should know?
Fix the intern's workCheck tools/deposit_calculator.html against business_rules.md. Find every mistake, explain each in plain English, and save a fixed version.
Surprise meMake me something useful for this business that I didn't ask for.

Three habits of people who use agents well

  1. Read before you approve. When the agent asks permission to do something, read what it is.
  2. Check one number. Agents sound confident even when they're wrong.
  3. Never use real data in practice. No real customer information, passwords, or company files.

Want more? Add GitHub (optional)

A free GitHub account plus GitHub Desktop gives your project a version history: every change saved, labeled, and reversible. Ask your agent to "save my work" after each change. To share a tool as a live web link, publish it with GitHub Pages from a public repository, with the tool named index.html.
